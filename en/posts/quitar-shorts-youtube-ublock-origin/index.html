How to hide YouTube Shorts on desktop with uBlock Origin

Rodrigo Iglesias // 2024-03-01 // 519 words // 3 min

Hide YouTube Shorts on desktop with uBlock Origin and a filter list. Firefox instructions, a manual alternative and what has changed in Chrome. Includes video.

Watch the tutorial on YouTube (in Spanish).

I open YouTube to watch a longer video, and there are the Shorts again. If you would rather leave them out when using your computer, you can hide them with uBlock Origin and a filter list. That lets you use your existing blocker without installing another extension just for this.

The video is from March 2024. I updated the links and browser information on 26 October 2026; the steps below are for uBlock Origin in Firefox.

What you need to hide Shorts

Install uBlock Origin from Firefox Add-ons if you do not have it yet. We will use Hide YouTube Shorts by Harren06, a fork of gijsdev’s list with more recent fixes.

These filters hide elements such as Shorts sections and their sidebar entry. The list preserves videos in your History. The change applies to the browser you configure, rather than your YouTube account across all devices.

Recommended method: import a filter list

Subscribing to a list lets uBlock Origin download its updates. If YouTube changes something and the author fixes the rules, you can receive that fix without copying them again yourself.

  1. Click the uBlock Origin icon and open its Dashboard using the cog.
  2. Go to Filter lists and scroll down to Custom.
  3. Check Import and paste this complete address:
https://raw.githubusercontent.com/Harren06/ublock-yt-shorts/main/list.txt
  1. Click Apply changes and check that the list is enabled.
  2. Reload YouTube and check the homepage, search results and sidebar.

You can open the list file to copy its URL. Use the text file’s address, rather than the repository page. I show the process from 1:16 in the video.

Alternative: paste the rules into My filters

To do it manually, open that file and copy its contents. Go to Dashboard → My filters, paste them and click Apply changes. Reload YouTube.

This gives you a copy of the rules at that moment: anything pasted there will not update from the repository. That is why I prefer subscribing. If you switch from manual rules to the list, remove only the Shorts rules you pasted earlier to avoid keeping duplicate copies.

What if I use Chrome?

The original uBlock Origin is no longer available in Chrome. The same developer offers uBlock Origin Lite, whose interface differs from the one in the video.

Current Lite versions support custom filters and external lists as of June 2026. If you use Lite, look for list importing in its settings; the steps and filter compatibility may differ from uBlock Origin in Firefox.

Frequently asked questions

Does this block Shorts forever?

It keeps them hidden while the rules work. YouTube changes its website and can break individual filters. If Shorts return, check that the blocker and list are enabled, then update the list under Filter lists. You can also check the repository’s issues.

Does it remove Shorts from the mobile app too?

No. This tutorial changes the YouTube website in the browser where you install the blocker.

How do I show Shorts again?

Uncheck the list under Filter lists, apply the changes and reload YouTube. If you used the manual method, remove those rules from My filters.
