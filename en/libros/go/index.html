Programación práctica · Vol. 2

Aprende Go paso a paso: 100 ejercicios resueltos

100 solved exercises in Go: from your first programs to concurrency, HTTP and two final projects.

Rodrigo Iglesias · Spanish edition

View on Amazon ↗

Inside the book

One hundred exercises with complete solutions and explanations, covering first programs, functions, Unicode, collections, pointers, errors, interfaces, files, testing and generics. Later exercises introduce goroutines, channels, cancellation and HTTP with JSON.

Two final projects bring these topics together: a terminal task manager with JSON storage and a concurrent website monitor.

Who it is for

Students, self-taught learners and programmers learning Go through practice. No knowledge of C or the first volume is required. This book is available in Spanish.

Book resources

Examples use Go 1.27 and the standard library. The public repository contains the solutions and tests. You can check reported issues or report an error through GitHub Issues.
