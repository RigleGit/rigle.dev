3dslibris: ebooks and manga on Nintendo 3DS

Read EPUB, PDF and CBZ manga on your Nintendo 3DS with 3dslibris, a free, open-source reader. Download the app, install it and explore its reading features.

3dslibris turns your Nintendo 3DS into an ebook and manga reader. It is a free, open-source homebrew application based on Ray Haleblian’s Nintendo DS reader, dslibris. It runs on the console and in the Azahar emulator.

What you can do with 3dslibris

  • Read books and manga in ten formats: EPUB, FB2, TXT, Markdown, RTF, ODT, MOBI, PDF, CBZ and XPS.
  • Organise your library into folders, with grid and list views, custom covers, sorting and touch navigation.
  • Read in portrait or landscape, with handedness settings and a separate reading direction for PDF and CBZ.
  • Make reading comfortable: adjust font size, spacing, six themes and EPUB publisher layout options, globally or for individual books.
  • Pick up where you left off: progress and bookmarks are saved across folders, with an option to reopen your last book at startup.
  • Zoom into documents and manga, pan around the page, navigate chapters and use a full-page preview in PDF, CBZ and XPS.

EPUB reading includes a table of contents, bookmarks, go-to-page and cached pagination for future openings. Bundled fonts extend language coverage, including Latin, Cyrillic, Greek, CJK, Arabic and Hebrew scripts.

How to install 3dslibris

You need a Nintendo 3DS set up to run homebrew. Copy your books to the SD card; the application does not include a book download catalogue.

Universal-Updater: the recommended option

  1. Find and install 3dslibris in Universal-Updater.
  2. Launch the application once to create its folders.
  3. Copy your books to sdmc:/3ds/3dslibris/book/ on the SD card. You can organise them into subfolders.
  4. Open 3dslibris again and choose a book. The library includes QuickStart.txt, a guide to menus, settings and navigation.

Manual installation: CIA or Homebrew Launcher

Download the files from the latest published release:

  • CIA: install 3dslibris.cia and follow steps 2–4 above. This version bundles the required fonts and resources.
  • 3DSX: download 3dslibris.3dsx and 3dslibris-sdmc.zip. Extract the ZIP to the SD card root, place the executable at sdmc:/3ds/3dslibris/3dslibris.3dsx and your books in sdmc:/3ds/3dslibris/book/. Run the application from Homebrew Launcher.

Formats and limitations

FormatWhat to expect
EPUB 2 and 3Text reflow, table of contents, bookmarks, configurable fonts and cached pagination.
FB2, TXT, RTF and ODTText reading with the formatting supported by each parser.
Markdown (.md and .markdown)Headings, emphasis, lists, blockquotes and code spans in the text reader.
MOBIExperimental support. Some books take longer to open or lose part of their formatting.
PDF, CBZ and XPSPage viewer with zoom, pan and navigation. CBZ supports natural page ordering and chapters through ComicInfo.xml.

DRM-protected books are not supported. The EPUB engine is not a full browser: complex layouts, some tables and parts of CSS may be simplified. Some layout changes require reopening the book. The project documentation lists known limitations.

Giving hardware we already own another use

I started 3dslibris to give a console I already owned another use. I maintain it as an open-source project so other people can use it, suggest improvements and contribute. Community suggestions and bug reports help shape its development.

For questions or ideas, visit the project discussions. To report a reproducible bug, open a GitHub issue with the version, console model, book format and steps to reproduce it.

If you are curious about how it works, I wrote about the port, MuPDF integration and what I learned in the 3dslibris development article. The repository has the code and contribution instructions.
